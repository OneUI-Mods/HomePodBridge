# Reliability audit — 2026-11-18

## 経路準備のキャンセル時に専用ヘルパーが残る

An InterruptedException during route readiness could leave the helper and its scoped rule active. A partial line could bypass the timeout. Read a bounded marker under a deadline; failure closes the helper. Cleanup preserves cancellation while allowing the helper EXIT trap to run. Tests use only local shell fixtures; no real audio, root, routing or device restart is exercised.

No feature switches, boot preferences, signing identity, target scopes or Android 16/17 compatibility gates are changed. This is a source fix and regression check, not proof of physical-device behavior. No release APK is distributed by this audit.
