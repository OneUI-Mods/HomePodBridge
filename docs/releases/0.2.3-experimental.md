# HomePodBridge 0.2.3-experimental

端末起動後、設定や互換性データが利用できる初回ロック解除まで、フックの初期化を待つようにしました。解除前の初期化失敗により、機能が使えないまま残る場合を防ぎます。

通常の再ロックで初期化をやり直すことはなく、消灯時の省電力・セキュリティ動作と保存済みの設定を維持します。新しい常駐サービスや定期確認は追加していません。
署名済みAPKを上書きしてください。対象プロセスの次の起動から新しい初期化処理が使われます。端末の対応範囲は従来どおりです。

Initialization now waits for the first user unlock before accessing settings and cached compatibility data. Existing settings, supported environments, and screen-off power/security behavior are preserved. There is no new resident service or polling. Install the signed update; the startup change takes effect when the target process next starts.
